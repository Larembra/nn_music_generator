Проект: Генерация музыки с помощью рекуррентной нейронной сети

В рамках данного проекта была разработана рекуррентная нейронная сеть (РНС) для генерации музыкальных композиций, используя текстовое представление музыки в ABC-нотации.

Пример записи в ABC-нотации:

X: 1
T: Cooley's
M: 4/4
L: 1/8
R: reel
K: Em
V: Melody
|:D2|EB{c}BA B2 EB|~B2 AB dBAG|FDAD BDAD|FDAD dAFD|
EBBA B2 EB|B2 AB defg|afe^c dBAF|DEFD E2:|
|:gf|eB B2 efge|eB B2 gedB|A2 FA DAFA|A2 FA defg|
eB B2 eBgB|eB B2 defg|afe^c dBAF|DEFD E2:|

Для работы с моделью скачайте все с ветви master и запустите файл "nn_for_music.py" (Рекомендуется генерировать несколько мелодий подряд, так как в начале генерации модель еще не имеет сформированного скрытого состояния).

Для воспроизведения сгенерированной музыки воспользуйтесь онлайн-проигрывателем ABC-нотации, например https://abc.rectanglered.com/ (вставьте туда текст музыки).

Также в проекте присутствует файл с примерами сгенерированных музыкальных произведений "generated_song_examples.abc".
